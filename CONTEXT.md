# MD-EXAFS Ecosystem

The multi-tiered software ecosystem for ensemble-averaged Extended X-ray Absorption Fine Structure (EXAFS) spectroscopy from molecular dynamics trajectories.

## Language

### Software Components

**MD-EXAFS Core (`md_exafs`)**:
The foundational Python library providing trajectory analysis, Debye–Waller/MSRD extraction, FEFF card/input generation, and path-resolved EXAFS spectral reconstruction without framework dependencies.
_Avoid_: larch-cli-wrapper, alc-dls-exafs, exafs-core

**MD-EXAFS CLI (`md-exafs`)**:
The command-line interface tier providing workstation-scale, single-node execution and CLI workflows on top of MD-EXAFS Core.
_Avoid_: larch-cli, larch-wrapper

**AiiDA-FEFF**:
The AiiDA plugin tier providing provenance tracking, daemon-driven multi-node HPC scheduling, and batch execution for FEFF and MD-EXAFS workflows.
_Avoid_: aiida-larch

**AiiDAlab-EXAFS**:
The interactive web application tier providing GUI-based job submission, monitoring, and visual analysis inside AiiDAlab.
_Avoid_: aiidalab-feff-app

### Architecture and Data Concepts

**Batch Shard (`batch_shard.h5`)**:
A self-contained HDF5 archive containing the spectra and raw path decomposition data generated by a single batch of FEFF calculations on a compute node.
_Avoid_: micro-hdf5, raw-contribution-file

**Ensemble Archive (`ensemble_results.h5`)**:
The consolidated HDF5 archive storing the full ensemble-averaged spectra, per-site averages, and merged path decomposition for an entire trajectory.
_Avoid_: results-database

**ExafsArchiveData**:
The consolidated AiiDA data node wrapping either a `batch_shard.h5` or `ensemble_results.h5` file, providing high-level property accessors for spectra, Fourier transforms, and scattering paths.
_Avoid_: XasData-only, PathContributionsData-only
